# PharmaMind — Offline Showcase Edition
A polished academic front-end demonstration that runs directly in the browser with no installation, API keys, Node.js, NPM, accounts, or internet connection.

Open `public/index.html`.

The Study Generator creates grounded practice material locally from pasted lecture text. The Drug Interactions module includes a small curated demonstration dataset and clearly labels unknown combinations. Evaluation data is stored locally in the browser.

Educational demonstration only; not for clinical decision-making.
